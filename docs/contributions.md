# Contributing to this site

The content on this website is created by people at RU who do hands-on scientific computing or work with HPC clusters. If you solved a problem you encountered, or are able to write documentation or tutorials broadly useful to your peers at RU, please consider contributing to this website. All content is hosted [on GitHub, where you will find specific contrubution instructions](https://github.com/reykjavik-university/compute-docs).
