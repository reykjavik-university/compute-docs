# Welcome to Scientific Computing at RU!

### Available HPC resources

#### Local HPC cluster

 - [Documentation and access instructions](https://computewiki.ru.is/)

#### IREI resources

Reykjavik University is a parner to the Icelandic Research e-Infratructure projects, and has access to its resources.

 - [HPC documentation for the Elja cluster](https://irhpcwiki.hi.is/)
 - [Acquiring access](https://irhpcwiki.hi.is/docs/intro/)

#### Large-scale computing resources

Reykjavik University has access to large-scale computing resources at the [LUMI supercomputer](https://lumi-supercomputer.eu/) in Finland and other sites funded by the European High-Performance Computing Joint Undertaking ([EuroHPC JU](https://www.eurohpc-ju.europa.eu/)).
