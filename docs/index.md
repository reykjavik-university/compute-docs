# Welcome to Scientific Computing at RU!

This website hosts documentation on HPC access and scientific computing resources avialable to the faculty and students of Reykjavik University. It is built by the people who use these resources. Join our chatroom (see below) and consider [contributing](contributions.md) content. Check the [news](news.md) for upcoming events.

### Available compute resources

A non-exhaustive list of resources available to RU is below.

#### Local HPC cluster

 - [Documentation and access instructions.](https://computewiki.ru.is/)

#### IREI resources

Reykjavik University is a parner to [the Icelandic Research e-Infratructure (IRE) project](https://www.irei.is), and has access to its resources, including HPC clusters and the IREI cloud.

 - See [www.irei.is](https://www.irei.is) for more information.
 - [HPC documentation for the Elja cluster.](https://irhpcwiki.hi.is/)
 - [Acquiring access to Elja.](https://irhpcwiki.hi.is/docs/intro/)

#### Large-scale computing resources

Reykjavik University has access to large-scale computing resources at the [LUMI supercomputer](https://lumi-supercomputer.eu/) in Finland and other sites funded by the European High-Performance Computing Joint Undertaking ([EuroHPC JU](https://www.eurohpc-ju.europa.eu/)).
